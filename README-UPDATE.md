# Обновление сайта (фото + панель админа)

## 1. База данных (Supabase -> SQL Editor)

Выполните файл `migration-photos.sql` один раз. Он добавляет:
- колонку `image_url` в таблицу новостей;
- публичный storage-бакет `news-images` (читать могут все, загружать/удалять — только админы).

## 2. Файлы сайта

Замените на GitHub три файла:
- `index.html` — в форму новости добавлено поле фото, добавлена панель «Цены» и «Чайная карта»;
- `supabase-app.js` — загрузка фото в Storage, предпросмотр, редактирование цен и чаёв, админ видит пожелания клиентов;
- `styles.css` — допишите в конец содержимое `styles-additions.css` (или замените файл целиком, если объедините).

## 3. Сделать себя админом

См. `ADD-ADMIN-apce2.sql`: сначала регистрация на сайте с подтверждением почты, затем один UPDATE-запрос.

## Что проверить после обновления

1. Войти как apce2@mail.ru -> «Админка»: сохранить цены, изменить описание чая.
2. Создать новость с фото -> увидеть её на главной с картинкой.
3. Оставить тестовую запись клиентом -> в админке видны контакты и пожелание.
